## أهم مشاريع الـ Machine Learning والبرمجيات

### مشروع: RAG Knowledge Base Chatbot
عشان يثبت خبرته في نماذج الـ LLMs، زين بنى شات بوت ذكي بيعتمد على تقنية الـ RAG جاهز للـ Production، بيقدر يجاوب على الأسئلة من ملفات ومستندات معينة.
- **التقنيات المستخدمة:** Python, RAG, FAISS, FastAPI, Hybrid Search, Docker, AWS EC2.
- **التفاصيل:** بنى RAG Pipeline بـ LangChain بيدمج Retrieval وPrompt Engineering وLLM Inference. عمل Hybrid Search باستخدام FAISS للبحث الدلالي وBM25 للكلمات وEnsembleRetriever، وبنى FastAPI REST Backend، وحط التطبيق في Docker ورفعه على AWS EC2، ودمج LangSmith للـ Tracing والمراقبة وتصحيح الأخطاء.

### مشروع: متوقع الدوري الإنجليزي (نظام MLOps متكامل)
دة واحد من أهم مشاريع البورتفوليو بتاعته، عبارة عن سيستم بيتوقع نتايج ماتشات الدوري الإنجليزي والترتيب النهائي للفرق.
- **التقنيات المستخدمة:** Python, ZenML, MLflow, XGBoost, Supabase (PostgreSQL), Streamlit.
- **التفاصيل:** بنى Data وTraining وEvaluation وPrediction Pipelines بـ ZenML، واستخدم MLflow للـ Experiments وModel Registry وترقية الـ Champion Model. خزن البيانات في Supabase PostgreSQL والـ Artifacts في AWS S3، ورفع Docker Image على ECR وشغله على EC2. Cron Job أسبوعية بتقيس دقة التوقعات وبتعمل Retraining كامل لو الدقة نزلت عن الحد.

### مشروع: FPL Vision (مساعد الفانتازي الإنجليزي بالـ AI)
المشروع دة زين عمله بشغف شخصي عشان بيحب الفانتازي. هو مساعد ذكي بيساعد مدربين الفانتازي ياخدوا أحسن قرارات لفرقهم بناءً على تحليلات البيانات.
- **التفاصيل:** جمع وعمل Feature Engineering لبيانات أكتر من 700 لاعب و20 فريق من FPL API، ودرب XGBoost يتوقع نقاط كل لاعب، وخزن التوقعات في PostgreSQL وبيحدثها كل Gameweek. رفع Streamlit App في Docker على Azure App Service، واستخدم Azure Blob Storage وGitHub Actions.

### مشروع: نظام التعرف على الوشوش (Real-Time Facial Recognition)
سيستم Computer Vision بيتعرف على الوشوش في الوقت الفعلي وبيقدر يضيف أشخاص جداد بسهولة.
- **التفاصيل:** استخدم موديل FaceNet مع MediaPipe، وحقق دقة 98% على مجموعة بيانات LFW، ورفعه على Hugging Face Spaces.

### مشروع: عربية ذكية ذاتية القيادة (Smart Car)
تطبيقاً للي درسه في الـ Embedded Systems، بنى عربية روبوت بتمشي لوحدها بناءً على إحداثيات اليوزر بيدخلها.
- **التفاصيل:** استخدم Arduino مع MQTT للتحكم اللاسلكي، ودمج ميزة التعرف على الصوت عشان العربية تتحرك بالأوامر الصوتية.

### مشروع: تحليل بيانات WHO COVID-19 العالمية
حلل أكتر من 250 ألف سجل يومي لأكتر من 200 دولة ومنطقة باستخدام Python وPandas وNumPy وMatplotlib وSeaborn وPlotly، وعمل تنظيف وFeature Engineering وEDA عشان يوضح اتجاهات الصحة العامة.

### مشروع: LAN Chat Room
بنى تطبيق Client-Server بـ Python وSockets وMultithreading بيدعم Text وVoice وVideo لحد 10 مستخدمين في نفس الوقت. جيت هاب: github.com/Zain3627/Chatroom.

### مشروع: Java Banking System
